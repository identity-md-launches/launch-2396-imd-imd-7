# IMD任务成本与毛利计算器

简体中文、纯前端的单页成本工具，用于估算一批 IMD 任务的总成本、毛利和盈亏平衡收费。完整可部署网站位于 **`dist/`**，无需服务器端程序或数据库。

## 使用

1. 打开网站即载入虚构案例 A。
2. 修改任务次数、整批重试次数、每次 IMD 用量、手动美元单价、整批其他成本、人工成本和客户收费。结果即时更新。
3. “载入示例”恢复 A；“清空”把全部输入和结果设为 0。
4. 出现中文错误提示时，结果暂停显示。修正字段后自动恢复，也可用“前往修改”定位首个错误。

N、R 只接受非负整数；其余字段接受非负十进制小数，小数点使用 `.`。单项最多 120 个字符；空白、负数、单位、千位逗号和科学计数法会得到明确提示，不会偷偷按 0 计算。清空按钮写入的是真正的 `0`。

R 是**所有任务合计**的额外执行次数。E、H、S 都是整批金额。价格由使用者手动填写，所有输入只保留在当前页面内存中，刷新恢复案例 A，不保存或上传。

> 本工具仅按输入进行成本估算；IMD价格和每次费用需自行核实，结果不代表实际收益承诺。毛利仅扣除已填写成本，不等同于扣除全部经营费用后的净利润。

## 安装、开发与生产预览

需要 Node.js 22.12 或更新版本及 npm。首次安装需要访问 npm；网站运行不依赖第三方网络服务。

```sh
npm ci
npm run dev
```

重新构建并预览最终导出：

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

打开命令显示的本地 URL。也可使用任意静态 HTTP 服务器直接服务 `dist/`。请通过 HTTP/IPFS 网关访问，直接双击 `file://` 下的 HTML 可能被浏览器模块安全策略阻止。

构建使用 Vite + TypeScript，界面使用原生语义 HTML/CSS，无客户端框架依赖。`package-lock.json` 固定依赖。`dist/` 已包含生产 HTML、JS、CSS、本地字体、favicon 和分享图片，不能只上传 `index.html`。

## 计算与精度

```text
总执行次数 = N + R
总IMD消耗 = (N + R) × U
IMD成本 = 总IMD消耗 × P
总成本 = IMD成本 + E + H
毛利 = S − 总成本
盈亏平衡收费 = 总成本
```

每次首次执行或重试使用同一个 U；E 和 H 各加一次。这是估算假设，不代表实际收费或退款规则。不计算毛利率。

`src/calculator.ts` 使用 BigInt 系数与十进制小数位保存精确数值，加法、乘法及盈亏判定均不提前舍入。仅显示时四舍五入：美元固定两位，IMD 最多六位。极小非零毛利或用量有额外提示，避免显示精度导致误解；美元显示不产生负零。

### 重跑浏览器验证

```sh
npx playwright install chromium webkit
npm run build
npm run test:browser
```

脚本会启动一个临时静态服务器，在 `/preview/` 加载 `dist/`，结束时关闭浏览器和服务器，并更新 `artifacts/` 的结果与截图。可选 `IMD_TEST_DEPENDENCIES` 指向独立安装依赖的目录；普通 `npm ci` 无需设置。WebKit 无法启动时会明确记录为未验证，不会假报通过。

给定的 `taste.mjs` 属于任务输入，交付时会被平台移除，未复制成本站运行依赖；其最终结果已保留。交付后的核心交互检查可用上述脚本独立重跑。

## 已知验证限制

- WebKit 因缺少宿主共享运行库未能启动，未验证 Safari、真实 iPhone 或 Android 设备，也未验证 Firefox。
- 已验证 200% **文字放大**和 320 像素重排；未执行浏览器原生 200% 缩放或真实屏幕阅读器会话。自动无障碍扫描不等于完整无障碍认证。
- 实际 IPFS 公网可达性和第三方分享平台的预览抓取尚未验证。分享图已在生产子路径请求中返回成功。
- 需要支持 ES2022、BigInt、CSS Grid 的现代浏览器。容器查询用于文字放大时的自适应，极旧浏览器不在验证范围内。
